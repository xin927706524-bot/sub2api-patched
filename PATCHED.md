# Sub2API Patched Distribution

This repository tracks official [Sub2API](https://github.com/Wei-Shaw/sub2api)
releases and adds two administrator-controlled display fields:

- group display rate multiplier
- group display token multiplier

Both values only change what normal users see in user-facing responses. Billing,
database values, administrator endpoints, and internal accounting continue to
use the real values.

## Update channel

The application still checks `Wei-Shaw/sub2api` for update notifications. When
an update is installed, it looks for the same tag in this repository and refuses
to install the official binary as a fallback. This prevents an in-app update
from silently removing the patch.

The `Adapt upstream release` workflow checks the official latest release every
30 minutes. For a new official release, it merges the latest patched baseline,
updates the version, regenerates backend code, builds the frontend and backend,
and runs focused tests. It pushes a new tag only after all checks pass. If
adaptation fails, it opens an issue and leaves the existing patched release
unchanged.

## Deployment

Download the release archive matching the target platform, or use the matching
image from GitHub Container Registry. Release assets are generated by the same
release workflow as the official project.

For an existing installation built from this repository, use the in-app update
button after the matching patched release has finished publishing. There is no
need to reinstall manually for every upstream release.
